# 구현 구조

## 실행 구조

`python -m myth` → Uvicorn → FastAPI API 및 `web/` 정적 파일. 별도 번들러, 외부 데이터 서비스, AI API 키는 필요하지 않습니다. 기본 실행은 개인용 로컬 서버입니다.

- `myth/app.py`: HTTP 라우팅, 같은 출처의 쓰기 요청 보호, 파일 내보내기.
- `myth/store.py`: 트랜잭션·검증·마이그레이션·버전·병합·백업·연대기.
- `web/app.js`: 아카이브 탐색, 입력 폼, 원고 자동 저장, 복구용 브라우저 초안.
- `web/styles.css`: 데스크톱 작업실과 모바일 레이아웃.
- `tests/test_workstation.py`: 격리된 DB를 사용하는 API 통합 테스트.
- `scripts/browser_smoke.py`: 임시 서버와 DB에서 실제 Chromium으로 편집·저장·복원을 확인하는 테스트.

## 저장 모델

SQLite의 독립 테이블로 전역 객체(`entities`), 시점이 있는 객체 관계(`relations`), 자료 그룹(`groups`), 그룹 소속(`memberships`), 시간별 속성(`states`), 외전·서적(`documents`), 장·절(`chapters`), 수정 이력(`versions`)을 구분합니다. 레코드는 고유 ID와 수정 번호를 갖고, 확장 가능한 `data` 객체를 저장합니다. `schema_migrations`에 현재 스키마 버전 1을 기록합니다. 새 스키마 도입 시 명시적인 마이그레이션을 추가해야 합니다.

관계는 이름 대신 ID를 참조합니다. 서버가 참조 대상, 공간·그룹·장절 계층의 순환, 잘못된 소속 및 중복 그룹 소속을 쓰기 트랜잭션 안에서 검증합니다. 기본 객체 유형은 생성 뒤 고정되며, 세부 분류와 사용자 정의 정보는 수정 가능합니다. 장·절은 같은 원고 안에서 이동할 수 있습니다. 다른 서적으로의 장 이동은 제공하지 않습니다.

## 시간 표현

시간은 `mode`로 `unknown`, `absolute`, `before`, `after`, `range`를 구분합니다. 숫자 연도는 필요한 경우에만 저장합니다. 미확정은 `null`이며 0이나 임의 연도로 보정하지 않습니다. 상대 시간은 기준 사건 ID를 참조합니다. 사건 간 선후 관계는 날짜를 생성하지 않고 위상 정렬에 사용하며, 순환과 날짜 불일치를 충돌로 표시합니다.

숫자로 확정된 관계·상태의 양 끝은 포함됩니다. 한쪽 끝이 비어 있고 반대쪽은 확정되면 열린 기간입니다. 명시적인 미확정 시점이 있으면 유효 여부를 단정하지 않습니다. 타이틀을 고르면 해당 작품의 기간과 겹치는 전역 상태·소속을 조회합니다. 작품 미등장 여부가 인물의 존재나 다른 조직 소속을 제거하지 않습니다.

`states.data.exclusive`로 한 시점에 하나의 값만 가능한 속성을 표시합니다. 집단 소속은 복수 허용입니다. 통치·갤럭시 마스터 관계에서 공동 관계를 의도했다면 배타성을 해제할 수 있습니다. 충돌 검사는 경고이며 원본 기록을 자동 수정하거나 삭제하지 않습니다.

## 변경과 복구

편집 API의 수정 번호가 오래되면 409로 거절합니다. 객체 폼과 원고는 브라우저 임시 초안을 별도로 보존하며, 서버에 저장되지 않은 내용을 화면에 표시합니다. 원고 저장은 직렬화하여 한 창 안에서 요청 순서가 뒤바뀌는 것을 방지합니다.

삭제는 기본적으로 `deleted_at`을 기록합니다. 그룹 소속 제거만 실제 참조 행을 제거하며 전역 객체에는 영향을 주지 않습니다. 병합은 충돌 필드마다 유지할 값을 명시적으로 선택해야 하며, 원본을 휴지통에 남기고 현재 참조를 대상 ID로 바꿉니다. 분할은 선택한 확장 필드와 관계를 새 객체로 복사하고 원본 및 기존 참조를 보존합니다. 연결을 자동 추측해 나누지 않습니다.

JSON 백업은 사용자 데이터와 이력을 포함합니다. 가져오기는 전체를 검증한 뒤 하나의 트랜잭션으로 적용합니다. 기본 병합 모드는 기존 ID의 다른 내용을 덮어쓰지 않습니다. 전체 교체는 확인 문자열 `REPLACE`를 요구합니다. 복원 직전 JSON 사본은 DB와 같은 디렉터리 아래 `backups/`에 저장합니다. 잘못된 버전 스냅샷으로 다른 객체나 다른 서적의 장을 덮어쓸 수 없도록 대상 ID와 소유 원고를 검증합니다.

## 현재 범위

저장은 이 서버의 SQLite 파일을 기준으로 합니다. 여러 기기 동기화·계정 권한·공동 편집 서버는 포함하지 않습니다. 우주 탐색은 계층과 관계 목록이며 임의 좌표 지도나 천체 위치를 생성하지 않습니다. 원고는 Markdown을 포함하는 평문 편집기이며, 서식 있는 WYSIWYG 편집기나 자동 세계관 생성기는 포함하지 않습니다. 대규모 아카이브에서는 페이지 단위 조회, 검색 인덱스, 버전 비교 화면을 후속 작업으로 추가할 수 있습니다.
