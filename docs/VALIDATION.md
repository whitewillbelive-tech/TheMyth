# 검증 기록

실행 환경: Python 3.12.14, FastAPI 0.141.1, Uvicorn 0.52.1, SQLite, Node 24.22.1(구문 검사만), Playwright 1.62.0 및 시스템 Chromium. 기능 테스트는 임시 디렉터리에 별도 DB를 생성했습니다. 실제 `data/myth.sqlite3`에는 확인된 초기 구조 8개 외에 테스트 자료를 넣지 않았습니다.

## 범위 및 미실시 항목

- 우주 좌표 지도·능력 법칙·미제공 인물 설정은 생성하지 않았습니다. 공간 계층과 관계 탐색을 제공합니다.
- 외부 호스팅 게시, 계정·권한, 다중 기기 동기화는 이번 구현에 포함하지 않았습니다.
- 새 클라우드 작업에서 게시된 스냅샷의 복원은 아직 검증하지 않았습니다. 현재 인스턴스의 실행과 재시작 안내 저장을 구분합니다.
- 원고는 평문/Markdown 편집기입니다. 대규모 검색 인덱스·관계망 그래프·버전 비교 화면은 다음 개선 후보입니다.

클라우드 환경 초안의 `install_script`와 `start_skill`을 저장했습니다. 저장은 확인되었으나, 환경 게시 및 새 작업 스냅샷 복원은 별도입니다. 현재 서버는 최종 코드로 재시작했고 HTTP 화면·API 응답과 초기 데이터 보존을 확인했습니다.
